Contributions are welcome, especially in the form of issues.

## Issues

If you come across any issue or would like to see support for a new feature/improvement, please
submit an issue.

## Pull requests

Before opening any pull request, please submit an issue about it first.

Keeping `agevault`'s codebase low on complexity is very important to me as I want to keep it
extremely accessible for review. Thus, I have to maintain a certain code style, so I prefer to
implement most of the features and bugfixes myself. There could be exceptions, of course.
